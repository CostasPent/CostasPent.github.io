# Kostas Pentarakis | Security portfolio

Live site: **https://costaspent.github.io**

My personal site for learning security in public. It has writeups of training labs, retired machines and finished CTFs, plus my education, experience and skills. I'm a computer science student at NKUA (University of Athens) aiming for a penetration testing internship.

Built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages. Plain CSS, a few lines of JavaScript for the theme toggle and the typing effect, no trackers.

## Writeup rules

- Only legal practice targets: training labs, retired machines and finished CTFs.
- No flags, passwords or anything about live systems.
- No active Hack The Box machines.
